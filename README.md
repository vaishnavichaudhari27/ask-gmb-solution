# SVS Enterprises

Premium interior design homepage built with React, Vite, Tailwind CSS, Framer Motion and Lucide React.

## Run locally

```sh
npm install
npm run dev
```

## Before publishing

- The original SVS Enterprises logo is used unchanged from `src/assets/svs-enterprises-logo.png`.
- Copy `.env.example` to `.env` and set `VITE_WHATSAPP_NUMBER` to the business WhatsApp number in international format, digits only.
- Replace the editable business contact and social profile placeholders in `src/App.jsx`.
- Replace the clearly labeled demo testimonial copy with approved client feedback.
- Connect the contact form in `src/App.jsx` to the preferred inbox or CRM; it currently validates fields in the browser but does not send submissions.

Interior photography is loaded from Unsplash URLs.
